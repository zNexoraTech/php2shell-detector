# Security policy

This repository contains **defensive detection** tooling only.

- It performs local, read-only checks. It does not exploit, and should not be
  extended to exploit, CVE-2026-109618 or CVE-2026-109619.
- Report issues with the detector (false positives/negatives, parsing bugs) via a
  GitHub issue.
- Do not file exploit details here. For the vulnerabilities themselves, follow the
  official PHP security advisories.

Only run the detector on systems you are authorized to assess.
